# ラーメン画像の差分計画

ラーメン写真を状況に合わせて変える計画のメモ。
①（食券ごと）は実装済み。②（お題ごと）は **保留**（不採用ではない。あとで検討し直すために残す）。

## ① 食券ごとの写真（実装済み・2026-10-11）

| 食券 | ファイル | 内容 |
|---|---|---|
| 小ラーメン | `src/assets/images/tickets/easy.jpg` | ヤサイの山を 0.72 倍に縮める |
| 大ラーメン | `src/assets/images/tickets/normal.jpg` | 元写真そのまま |
| 全マシマシ | `src/assets/images/tickets/hard.jpg` | ヤサイの山を 1.45 倍に伸ばす |
| 超ハード | `src/assets/images/tickets/super.jpg` | 1.25 倍＋暗めのトーン |

- 作り方：`python3 scripts/make_ticket_photos.py assets-src/ramen_original.jpg src/assets/images/tickets`
  - 丼の縁（rim）より上・中心付近だけを縦に伸縮し、上方向と左右へ滑らかに元に戻す（背景の筋が出ないように）
- 表示：`components/JiroArt.tsx` の `TicketPhoto`。食券購入の開始バーとプレビューで使用
- 限界：変わるのは **ヤサイの高さだけ**。ニンニク・アブラ・カラメ（スープの色）は変わらない
- 差し替え：撮り下ろしや AI 生成の写真に替える場合は、同じファイル名で置き換えるだけでよい

## ② お題ごとの写真（保留）

### やりたいこと
コール（例：ヤサイマシマシ ニンニク アブラマシ カラメ）に合わせて、提供される丼の写真が変わる。

### 検討結果
- 組み合わせを全部写真で用意するのは不可能（ヤサイ・ニンニク・アブラ・カラメ各 約10段階で約1万通り）
- **レイヤー合成**なら可能性あり：土台の写真に、背景を透明にした素材を重ねる

| レイヤー | 段階の案 | 枚数 |
|---|---|---|
| 土台 | スープ・麺・豚だけの丼 | 1 |
| ヤサイ | スクナメ / 普通 / マシ / マシマシ / チョモランマ | 5 |
| ニンニク | なし / 普通 / マシ / マシマシ以上 | 4（なしは素材不要） |
| アブラ | なし / 普通 / マシ / マシマシ以上 | 4（なしは素材不要） |
| カラメ | 普通 / カラメ / カラメマシ以上 | スープ部分の色調補正で表現（素材不要） |

- 素材はおよそ 15 枚。マシ×3〜×6 は見た目の段階をまとめる（写真では描き分けられない）
- ①のヤサイ伸縮（`make_ticket_photos.py`）はヤサイ層の代わりにも使える

### リスク
- 光の向き・角度・ボケ感が素材ごとにずれると、貼り合わせに見える
- AI 生成画像は背景が透明にならないので、切り抜き作業が必要
- 超ハードは丼の見た目から量を当てるモードなので、写真にするなら段階数を減らす必要がある（今は SVG の丼で 10 段階を描き分けている）

### 進め方（再開するとき）
1. ヤサイ 5 段階だけで試作し、リアルに見えるか確認する（①の伸縮方式で作れる）
2. 良ければ、ニンニク・アブラの素材を AI 画像編集で作る（同じ元写真から「ニンニクだけ増やす」等の差分を作り、差分部分を切り抜く）
3. 超ハードの段階数を写真で見分けられる数に合わせて調整する

### 画像の作り手
この作業環境には画像生成機能がない。次のどちらかが必要：
- AI Studio 等で生成してもらう（指示文はこちらで用意する）
- Gemini 等の API キーを環境のシークレットに設定してもらう
